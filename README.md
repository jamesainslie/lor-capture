# Life of Reily Capture

The installer for the Life of Reily capture extension for Google Chrome on macOS.

The extension adds a side panel to Chrome. It captures a vendor's product page
into the Life of Reily studio portal, so a product never has to be typed in twice.

The installer, `Life of Reily Capture.pkg`, is signed with a Developer ID Installer
certificate and notarized by Apple. It installs no app and no background process.
It writes two small files that enroll Chrome in the studio's Chrome management.
Chrome then installs the extension, pins it to the toolbar and keeps it up to date.
No other browser setting changes.

Installers are published on this repository's Releases page. Each one is
available only for as long as it is needed, then removed.
